Les 3 couleurs du verdict

  • VALUE EV ≥ seuil → mise ¼ Kelly plafonnée.
  • THIN EV positive mais sous le seuil → possibilité de mise réduite ou SKIP.
  • NO BET proba correcte mais cote vidée → interdiction formelle.

Les non-négociables

  • 1u = 1% de bankroll ; mise max 5% (3% exotique) ; combinés : toutes jambes +EV, ¼ Kelly, max 1u, max 3 jambes.
  • Loterie (10+ jambes) : budget séparé ≤ 2% de bankroll.
  • Zero Data Zero Calc : donnée manquante déclarée, jamais estimée en silence.
  • Le ledger prend TOUS les tickets (gagnants ET perdants) — biais de survie = hérésie.

Démarcation
