3. Doctrine héritée, et ce qu'elle devient

3.1 « Herbert Simon » — rationalité limitée

Le concept est réel : Herbert Simon, prix Nobel d'économie 1978. Au-delà d'un certain point, réfléchir davantage ne réduit plus l'incertitude ; les réponses restantes sont dans le monde réel. DÉDUIT — le nom, le prix et l'année sont des faits biographiques contrôlables ; la formulation « au-delà d'un point, réfléchir ne paie plus » est la lecture standard de Models of Man (1957), pas une citation littérale. NON VÉRIFIÉ sur le texte exact de 1957, non ouvert dans cette session.

Règle MARK1 n°1 : aucun module ne consomme plus d'un jour de travail avant qu'un clip ne soit publié. C'est cette règle qui justifie les six sorties du §2.1.

Le seul module qui répond à la question « un non-fan comprend-il ? ». Deterministe, zero dependance, zero LLM. Heuristique assumee, pas un modele.

import re

    "TikTok", "Instagram", "YouTube", "Twitch", "X", "Twitter", "France", "USA", "Paris",
    "NBA", "Netflix", "Google", "Apple", "Amazon", "Europe", "Afrique", "Asie", "Bresil",
    "Monsieur", "Madame", "Docteur", "Prix", "Nobel", "Lundi", "Mardi", "Mercredi",
    "Jeudi", "Vendredi", "Samedi", "Dimanche", "Janvier", "Fevrier", "Mars", "Avril",
    "Juin", "Juillet", "Aout", "Septembre", "Octobre", "Novembre", "Decembre")}

APPOSITION = re.compile(
    r"(?:,\s*(?:le|la|les|l|un|une)\s+[a-z\u00e0-\u00ff]+)|"
    r"(?:\b(?:le|la|les|l)\s+(?:streamer|cr\u00e9ateur|createur|youtubeur|influenceur|joueur|"
    r"acteur|rappeur|chanteur|artiste|animateur|podcasteur|entrepreneur|analyste|journaliste)\b)",
    re.I)

INTERNAL_HINT = re.compile(
    r"\b(?:ce|cet|le|la|les)\s+(?:stream|live|vod|clip|jeu|serveur|discord|chat|don|sub|raid|"
    r"vocal|salon)\b|\bcomme\s+(?:hier|la\s+derni[e\u00e8]re\s+fois|tout\s+a\s+l'heure)\b", re.I)

TOKEN = re.compile(r"[A-Za-z\u00c0-\u017f'\-]{2,}")


def _explained(tok: str, subject: str, whitelist) -> bool:
    t = tok.lower()
    if t in UNIVERSALS:
        return True
    if subject and t in subject.lower():
        return True
    return t in {w.lower() for w in whitelist}


def analyse(text: str, subject: str = "", explained_entities=(), internal_terms=()) -> dict:
    text = text or ""
    unexplained: list[str] = []
    # 1. entites propres non expliquees
    for m in TOKEN.finditer(text):
        tok = m.group(0)
        if not tok[0].isupper():
            continue
        if tok.lower() in STOPLIST or _explained(tok, subject, explained_entities):
            continue
        before = text[max(0, m.start() - 40):m.start()]
        after = text[m.end():m.end() + 45]
        if APPOSITION.search(after[:45]) or APPOSITION.search(before):
            continue
        if tok not in unexplained:
            unexplained.append(tok)
    # 2. termes internes fournis par la campagne (pseudo de la chaine, jeu, private joke)
    low = text.lower()
    hits = sorted({t for t in internal_terms if t and t.lower() in low})
    # 3. marqueurs de contexte (ce stream, comme hier...)
    markers = sorted({m.group(0).lower() for m in INTERNAL_HINT.finditer(text)})
    n_u, n_i = len(unexplained), len(hits)
    dep = min(1.0, 0.45 * n_u + 0.35 * n_i + 0.20 * len(markers))
    return {
        "context_dependency": round(dep, 3),
        "unexplained_entities": unexplained,
        "internal_terms": hits,
        "context_markers": markers,
        "verdict": "ok" if (n_u == 0 and n_i == 0) else "reject",
    }

Les trois mécanismes, ligne par ligne

MécanismeCe qu'il attrapePourquoi ce n'est pas un LLM
Entité propre non expliquéeTout mot capitalisé qui n'est ni dans STOPLIST, ni dans UNIVERSALS, ni le sujet, ni dans une apposition (« Sophie Rain, la créatrice … »)Un LLM répondrait « ça dépend du public » — donc rien. Ici la règle est univoque : 1 entité non expliquée = rejet, point.
Terme interneLes internal_terms fournis par la campagne (pseudo de chaîne, nom de jeu, private joke)Un LLM ne sait pas ce qui est interne à une communauté qu'il n'a pas lue. La campagne, si.
Marqueur de contexte« ce stream », « ce live », « comme hier », « la dernière fois »Détection de dépendance référentielle : un non-fan n'a pas d'antécédent. Purement lexical, donc testable.

Sortie : {context_dependency, unexplained_entities, internal_terms, context_markers, verdict}. context_dependency = min(1, 0,45·entités + 0,35·termes + 0,20·marqueurs) — c'est un indicateur de lecture, pas le critère de rejet. Le rejet est binaire : verdict = "reject" si une entité ou un terme interne subsiste.

libs/economy.py — 39 lignes"""economy — l'arithmetique du revenu. C'est le seul chiffre que MARK1 doit rendre rigoureux."""
from __future__ import annotations


def net_per_1k(cpm_usd: float, fee_pct: float = 0.10) -> float:
    return round(cpm_usd * (1 - fee_pct), 6)


def views_needed(net_target_usd: float, cpm_usd: float, fee_pct: float = 0.10,
                 approval_rate: float = 1.0) -> int:
    if cpm_usd <= 0:
        raise ValueError("cpm<=0")
    approval_rate = max(1e-6, min(1.0, approval_rate))
    raw_views = net_target_usd / (net_per_1k(cpm_usd, fee_pct) / 1000.0)
    return int(round(raw_views / approval_rate))


def revenue(approved_views: int, cpm_usd: float, fee_pct: float = 0.10,
            cap_usd_per_clip: float | None = None) -> float:
    gross = (approved_views / 1000.0) * cpm_usd
    net = gross * (1 - fee_pct)
    if cap_usd_per_clip is not None:
        net = min(net, cap_usd_per_clip * (1 - fee_pct))
    return round(net, 2)


def usd_per_hour(approved_views: int, cpm_usd: float, minutes_worked: float,
                 fee_pct: float = 0.10, cap_usd_per_clip: float | None = None) -> float:
    if minutes_worked <= 0:
        return 0.0
    return round(revenue(approved_views, cpm_usd, fee_pct, cap_usd_per_clip) / (minutes_worked / 60.0), 3)


def break_even_clips(net_target_usd: float, views_per_clip: int, cpm_usd: float,
                     fee_pct: float = 0.10) -> int:
    per_clip = revenue(max(1, views_per_clip), cpm_usd, fee_pct)
    if per_clip <= 0:
        return 0
    return int(-(-net_target_usd // per_clip))

def evaluate(c: dict, cfg: dict, platform: str, today: date | None = None) -> dict:
    today = today or date.today()

    rate = float(c.get("rate_usd_per_1k") or 0)

def _t(sec: float) -> str:
    sec = max(0.0, float(sec))
    h = int(sec // 3600)
    m = int((sec % 3600) // 60)
    s = sec % 60
    return f"{h:d}:{m:02d}:{s:05.2f}"


def _esc(text: str) -> str:
    return (text or "").replace("\\", "\\\\").replace("{", "(").replace("}", ")").replace("\n", " ")


def build(title: str, title_in: float, title_out: float, words, cfg: dict) -> str:
    """words = [{'start','end','word'}] — groupes de caption_max_words_per_line mots."""
    per = max(1, int(cfg.get("caption_max_words_per_line", 3)))
    lines = [HEADER]
    if title:
        lines.append(f"Dialogue: 1,{_t(title_in)},{_t(title_out)},MARK1_Title,,0,0,0,,{_esc(title)}")
    buf, start, end = [], None, None
    for w in words or []:
        if start is None:
            start = float(w["start"])
        buf.append(str(w["word"]).strip())
        end = float(w["end"])
        if len(buf) >= per:
            lines.append(f"Dialogue: 0,{_t(start)},{_t(end)},MARK1_Caption,,0,0,0,,{_esc(' '.join(buf))}")

        lines.append(f"Dialogue: 0,{_t(start)},{_t(end)},MARK1_Caption,,0,0,0,,{_esc(' '.join(buf))}")

import shutil, subprocess
from pathlib import Path

BINS = ("ffmpeg", "ffprobe")
FILTERS = ("ass", "gblur", "crop", "overlay", "scale")


def preflight() -> tuple[bool, list[str]]:
    problems = []
    for b in BINS:
        if not shutil.which(b):
            problems.append(f"binaire absent: {b}")
    if shutil.which("ffmpeg"):
        out = subprocess.run(["ffmpeg", "-hide_banner", "-filters"],
                             capture_output=True, text=True).stdout
        for f in FILTERS:
            if f" {f} " not in out:
                problems.append(f"filtre absent: {f} (libass requis pour ass)")
    return (not problems), problems


def filtergraph(cfg: dict, subs_name: str) -> str:
    w, h = int(cfg.get("video_w", 1080)), int(cfg.get("video_h", 1920))
    sig = int(cfg.get("blur_sigma", 20))
    return (f"[0:v]scale={w}:-2,split=2[fg0][bg0];"
            f"[bg0]scale={w}:{h}:force_original_aspect_ratio=increase,crop={w}:{h},"
            f"gblur=sigma={sig}[bg];"
            f"[fg0]scale={w}:-2[fg];"
            f"[bg][fg]overlay=(W-w)/2:(H-h)/2[ov];"
            f"[ov]ass={subs_name}[vout]")


def render_clip(src: Path, out: Path, subs_ass: Path, cfg: dict, workdir: Path) -> int:
    src, out = Path(src).resolve(), Path(out).resolve()

        print(f"R1 FAIL: source absente {src}"); return 2
    workdir = Path(workdir).resolve(); workdir.mkdir(parents=True, exist_ok=True)
    local = workdir / "MARK1_subs.ass"
    local.write_text(Path(subs_ass).read_text(encoding="utf-8"), encoding="utf-8")
    out.parent.mkdir(parents=True, exist_ok=True)
    cmd = ["ffmpeg", "-y", "-hide_banner", "-loglevel", "error", "-i", str(src),
           "-filter_complex", filtergraph(cfg, "MARK1_subs.ass"),

           "-c:v", "libx264", "-preset", "veryfast", "-crf", "20", "-pix_fmt", "yuv420p",

def _parse(path: str) -> dict[str, str]:
    out: dict[str, str] = {}
    try:
        with open(path, encoding="utf-8") as f:
            for line in f:
                line = line.strip()
                if not line or line.startswith("#") or "=" not in line:
                    continue
                k, v = line.split("=", 1)
                out[k.strip()] = v.strip().strip('"').strip("'")
    except OSError:
        return {}
    return out


def load(refresh: bool = False) -> dict[str, str]:
    global _cache
    if _cache is not None and not refresh:
        return _cache
    _cache = {}
    for cand in CANDIDATES:
        if os.path.exists(cand):
            _cache = _parse(cand)
            break
    return _cache


def get(key: str, default: str | None = None) -> str | None:
    env = os.environ.get(key)
    if env not in (None, ""):
        return env
    return load().get(key, default)


def mask(value: str | None) -> str:
    if not value:
        return "absent"
    if len(value) <= 8:
        return "*" * len(value) + f" ({len(value)}c)"
    return value[:4] + "..." + value[-2:] + f" ({len(value)}c)"


def doctor() -> list[tuple[str, str, str]]:
    """[(cle, etat, usage)] — etat = PRESENT / absent. Aucune valeur."""
    return [(k, "PRESENT" if get(k) else "absent", usage)
            for k, (_, usage) in REQUIRED.items()]

16.2 La procédure, dans l'ordre — à exécuter telle quelle

  1. Copier l'état actuel. cp -r MARK1 MARK1.bak.$(date +%F). Sans sauvegarde, un test cassé ne se distingue pas d'un seuil cassé.
  2. Modifier un seul fichier selon le tableau §16.1. Jamais deux à la fois : si les tests cassent, on ne saura pas lequel.
  3. Relancer la suite. cd MARK1 && python3 -m unittest discover -s tests -v.
      • Sortie attendue si le changement est neutre : Ran 28 tests in ~3.5s puis OK.
      • Si un test de comportement casse (par exemple test_too_long après avoir mis title_max_words à 12) : c'est le test qui a raison, sauf si le seuil devait changer — dans ce cas on met à jour le test, avec la nouvelle valeur, jamais un skip.
  4. Relancer le rendu, pas seulement les tests. python3 mark1.py render … puis ffprobe. Un changement de géométrie ou de .ass ne se voit pas dans un test unitaire.
  5. Écrire une ligne dans MARK1/TRACKING/MARK1_LOG.md : date, fichier touché, valeur avant, valeur après, résultat de la suite.
  6. Si un test échoue et que tu ne sais pas pourquoi : tu restaures MARK1.bak, tu écris l'erreur exacte dans le log, et tu t'arrêtes. Tu ne réécris pas un module pour le faire passer. Un test ajusté pour passer n'est plus un test, c'est une décoration.
