2. Décision d'architecture — ce qui sort du chemin, ce qui naît

MARK1 n'est pas une réécriture de la forge. C'est un dossier autonome ajouté à côté du code existant, qui n'en supprime aucune ligne et n'en modifie aucune. La règle appliquée est unique : une ligne de code n'entre que si elle sert l'une des trois fonctions du §4.

Invariant de nature — non négociable. MARK1 est une frégate du monde-forge CLIPPING. Même isolée, elle respecte les règles globales du monde : étanche (elle ne communique que par JSON), et sans contact avec la vidéo. Aucun fichier de MARK1 n'appelle ffmpeg, n'ouvre un conteneur vidéo, ne coupe, ne cadre, ne réencode. C'est la doctrine écrite du README.md de la forge, citée au §1 constat n°9. Produire un MP4 est une hérésie dans ce monde : le rendu appartient à un consommateur externe, qui lit le pack et rend la vidéo de son côté.

Le seul module qui répond à la question « un non-fan comprend-il ? ». Heuristique assumée, pas un modèle : il compte les entités propres sans apposition, les termes internes de la campagne, et les marqueurs de contexte (« ce stream », « comme hier »). APPOSITION = re.compile(
    r"(?:,\s*(?:le|la|les|l|un|une)\s+[a-z\u00e0-\u00ff]+)|"
    r"(?:\b(?:le|la|les|l)\s+(?:streamer|cr\u00e9ateur|createur|youtubeur|influenceur|joueur|"
    r"acteur|rappeur|chanteur|artiste|animateur|podcasteur|entrepreneur|analyste|journaliste)\b)",
    re.I)

    r"\b(?:ce|cet|le|la|les)\s+(?:stream|live|vod|clip|jeu|serveur|discord|chat|don|sub|raid|"
    r"vocal|salon)\b|\bcomme\s+(?:hier|la\s+derni[e\u00e8]re\s+fois|tout\s+a\s+l'heure)\b", re.I)

def _explained(tok: str, subject: str, whitelist) -> bool:
    t = tok.lower()
    if t in UNIVERSALS:
        return True
    if subject and t in subject.lower():
        return True
    return t in {w.lower() for w in whitelist}


def analyse(text: str, subject: str = "", explained_entities=(), internal_terms=()) -> dict:
    text = text or ""
    unexplained: list[str] = []
    # 1. entites propres non expliquees
    for m in TOKEN.finditer(text):
        tok = m.group(0)
        if not tok[0].isupper():
            continue
        if tok.lower() in STOPLIST or _explained(tok, subject, explained_entities):
            continue
        before = text[max(0, m.start() - 40):m.start()]
        after = text[m.end():m.end() + 45]
        if APPOSITION.search(after[:45]) or APPOSITION.search(before):
            continue
        if tok not in unexplained:
            unexplained.append(tok)
    # 2. termes internes fournis par la campagne (pseudo de la chaine, jeu, private joke)
    low = text.lower()
    hits = sorted({t for t in internal_terms if t and t.lower() in low})
    # 3. marqueurs de contexte (ce stream, comme hier...)
    markers = sorted({m.group(0).lower() for m in INTERNAL_HINT.finditer(text)})
    n_u, n_i = len(unexplained), len(hits)
    dep = min(1.0, 0.45 * n_u + 0.35 * n_i + 0.20 * len(markers))
    return {
        "context_dependency": round(dep, 3),
        "unexplained_entities": unexplained,
        "internal_terms": hits,
        "context_markers": markers,
        "verdict": "ok" if (n_u == 0 and n_i == 0) else "reject",
    }

libs/economy.py — 39 lignes"""economy — l'arithmetique du revenu. C'est le seul chiffre que MARK1 doit rendre rigoureux."""
from __future__ import annotations


def net_per_1k(cpm_usd: float, fee_pct: float = 0.10) -> float:
    return round(cpm_usd * (1 - fee_pct), 6)


def views_needed(net_target_usd: float, cpm_usd: float, fee_pct: float = 0.10,
                 approval_rate: float = 1.0) -> int:
    if cpm_usd <= 0:
        raise ValueError("cpm<=0")
    approval_rate = max(1e-6, min(1.0, approval_rate))
    raw_views = net_target_usd / (net_per_1k(cpm_usd, fee_pct) / 1000.0)
    return int(round(raw_views / approval_rate))


def revenue(approved_views: int, cpm_usd: float, fee_pct: float = 0.10,
            cap_usd_per_clip: float | None = None) -> float:
    gross = (approved_views / 1000.0) * cpm_usd
    net = gross * (1 - fee_pct)
    if cap_usd_per_clip is not None:
        net = min(net, cap_usd_per_clip * (1 - fee_pct))
    return round(net, 2)


def usd_per_hour(approved_views: int, cpm_usd: float, minutes_worked: float,
                 fee_pct: float = 0.10, cap_usd_per_clip: float | None = None) -> float:
    if minutes_worked <= 0:
        return 0.0
    return round(revenue(approved_views, cpm_usd, fee_pct, cap_usd_per_clip) / (minutes_worked / 60.0), 3)


def break_even_clips(net_target_usd: float, views_per_clip: int, cpm_usd: float,
                     fee_pct: float = 0.10) -> int:
    per_clip = revenue(max(1, views_per_clip), cpm_usd, fee_pct)
    if per_clip <= 0:
        return 0
    return int(-(-net_target_usd // per_clip))

def read(path: str) -> list[dict]:
    if not os.path.exists(path):
        return []
    with open(path, newline="", encoding="utf-8") as f:
        return list(csv.DictReader(f))


def append(path: str, row: dict) -> bool:
    """Idempotent sur clip_token. Rend True si la ligne a ete ecrite."""
    if not row.get("clip_token"):
        return False
    os.makedirs(os.path.dirname(os.path.abspath(path)) or ".", exist_ok=True)
    rows = read(path)
    if any(r.get("clip_token") == row.get("clip_token") for r in rows):
        return False
    new = not os.path.exists(path) or os.path.getsize(path) == 0
    with open(path, "a", newline="", encoding="utf-8") as f:
        w = csv.DictWriter(f, fieldnames=FIELDS, extrasaction="ignore")
        if new:
            w.writeheader()
        w.writerow({k: row.get(k, "") for k in FIELDS})
    return True


def update(path: str, clip_token: str, **changes) -> bool:
    """Point d'entree de l'operateur et du futur outil de statistiques (S17)."""
    rows = read(path)
    hit = False
    for r in rows:

            r.update({k: str(v) for k, v in changes.items() if k in FIELDS})
            hit = True
    if not hit:
        return False
    with open(path, "w", newline="", encoding="utf-8") as f:
        w = csv.DictWriter(f, fieldnames=FIELDS, extrasaction="ignore")
        w.writeheader()
        w.writerows(rows)
    return True

def _canonical(pack: dict) -> str:

    pt = pack_token(pack)

def _parse(path: str) -> dict[str, str]:
    out: dict[str, str] = {}
    try:
        with open(path, encoding="utf-8") as f:
            for line in f:
                line = line.strip()
                if not line or line.startswith("#") or "=" not in line:
                    continue
                k, v = line.split("=", 1)
                out[k.strip()] = v.strip().strip('"').strip("'")
    except OSError:
        return {}
    return out


def load(refresh: bool = False) -> dict[str, str]:
    global _cache
    if _cache is not None and not refresh:
        return _cache
    _cache = {}
    for cand in CANDIDATES:
        if os.path.exists(cand):
            _cache = _parse(cand)
            break
    return _cache


def get(key: str, default: str | None = None) -> str | None:
    env = os.environ.get(key)
    if env not in (None, ""):
        return env
    return load().get(key, default)


def mask(value: str | None) -> str:
    if not value:
        return "absent"
    if len(value) <= 8:
        return "*" * len(value) + f" ({len(value)}c)"
    return value[:4] + "..." + value[-2:] + f" ({len(value)}c)"


def doctor() -> list[tuple[str, str, str]]:
    """[(cle, etat, usage)] — etat = PRESENT / absent. Aucune valeur."""
    return [(k, "PRESENT" if get(k) else "absent", usage)
            for k, (_, usage) in REQUIRED.items()]

10.2 Ce que la V2 ne peut pas prouver toute seule

C'est le point le plus important de cette section, et il est structurel, pas un manque provisoire :

MARK1 ne rend pas la vidéo, donc il ne prouve pas que le clip est regardable. En V1, le rendu réel re-mesuré par ffprobe (1080×1920, h264, yuv420p) était une preuve de bout en bout. En V2, cette preuve appartient au consommateur externe, qui lit le pack et produit le MP4. MARK1 prouve une seule chose, mais il la prouve complètement : le pack est conforme, livrable, traçable, et le ledger est écrit. Si un clip sort mauvais à l'écran, la faute est en aval — dans le rendu du consommateur — et c'est là qu'il faut corriger, pas dans MARK1.

Conséquence directe sur le §12.1 : la Definition of Done de la V2 ne peut pas contenir « un MP4 1080×1920 re-mesuré par ffprobe ». Elle contient « un pack dans EXPORT/ et une ligne de ledger par clip ». C'est un recul assumé sur la preuve visuelle, et un gain sur la doctrine : c'est précisément parce que MARK1 ne touche plus la vidéo qu'il respecte le monde-forge CLIPPING.

17. L'outil de statistiques — contrat d'interface

MARK1 s'arrête au pack et au ledger. Il ne lit aucune statistique : aucune API de plateforme n'est appelée (invariant §16.3 n°1). Mais il y a un maillon manquant entre « le clip est publié » et « on sait s'il a rapporté » : quelqu'un doit regarder le lien et remplir les chiffres. Cette section fixe ce contrat maintenant, pour que le jour où l'outil est écrit, il n'ait rien à renégocier avec MARK1.

Ce que cette section n'est pas. Ce n'est pas la spécification de l'outil — celui-ci n'existe pas encore et n'est pas nommé ici. C'est la surface par laquelle il parle à MARK1, et qui ne bougera pas : deux entrées, un point d'écriture. Tout le reste est à lui.

17.1 La règle d'appariement — la seule chose non négociable

Le ledger est apparié par clip_token, jamais par le titre, la date ou l'ordre de publication. Un titre peut être modifié après publication ; deux clips peuvent partager le même titre ; l'ordre de publication n'est pas l'ordre d'export. Le clip_token est la seule clé qui survive à ces trois cas — c'est précisément pour ça qu'il contient le pack_token (§8.8).

Conséquence pratique : au moment de publier, l'opérateur colle le lien à côté du clip_token. C'est ce que fait mark1.py ledger --update <clip_token> --changes '{"clip_url": "…"}'. Sans ce lien, l'outil ne peut pas remonter au clip — il n'a rien à mesurer. Le lien est le seul geste manuel irréductible du système.
